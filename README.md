# 🎮 CYBER STRIKE - Multiplayer Web Shooter

เกมยิงปืนออนไลน์บนเว็บ (HTML5 Canvas 2D + Node.js + Socket.io + WebRTC)
- 🌐 เล่นกับเพื่อนได้แบบ Real-time หลายห้อง / หลายเซิร์ฟเวอร์
- 🎙️ ระบบเปิดไมค์สื่อสารความเร็วสูง (WebRTC Voice Chat)
- 🔑 เข้าสู่ระบบด้วย Google หรือสมัครสมาชิก
- 📊 หน้าแอดมินจัดการผู้เล่น และ Export ข้อมูลเป็น Excel (CSV)
- 📱 รองรับมือถือเต็มรูปแบบด้วย Dual Virtual Joysticks

---

## 🚀 วิธีติดตั้งและเปิดเล่น (Installation)

1. **ติดตั้งไลบรารี:**
   ```bash
   npm install
   ```

2. **เปิดเซิร์ฟเวอร์:**
   ```bash
   npm start
   ```
   *(หรือดับเบิลคลิกไฟล์ `start.bat` บน Windows)*

3. **เข้าเล่นเกม:**
   - บนคอมพิวเตอร์: เข้าผ่านเบราว์เซอร์ไปที่ `http://localhost:3000`
   - บนมือถือ (Wi-Fi เดียวกัน): เข้าผ่าน IP เช่น `http://10.66.8.7:3000`
   - รหัสผ่านแผงแอดมิน: `admin1234`
